## Codebase Patterns
- Tailwind design tokens live in tailwind.config.js (bg-*, text-*, accent-*, severity-*, status-*, shadow-glow*, shadow-elevation-*); glass / glass-hover / text-gradient utility classes live in src/app/globals.css. glass-hover already provides the lift + red-border-glow hover, so reuse it instead of hand-rolling hover shadows.
- Components are typed React.FC with 4-space indent, single quotes, no semicolons; client components start with 'use client'.
- /api/reports GET returns { success, data, pagination: { total, ... } } and accepts search/game/status/severity/limit query params — pagination.total is the cheap way to get counts (limit=1).
- The Intel Board (/intel) filters client-side via component state and refetches /api/reports on every filter change; its search filter is seeded from the ?search= URL param.
- Any client page using useSearchParams must be wrapped in <Suspense> or `next build` fails during prerender ("CSR bailout").
- ESLint is next/core-web-vitals: plain <img> triggers a warning — use next/image (with `unoptimized` for arbitrary external evidence URLs so remotePatterns config isn't needed).
- Pre-existing (accepted) lint warnings: react-hooks/exhaustive-deps in src/app/mod/page.tsx, src/app/report/[id]/edit/page.tsx, src/components/reports/CommentsSection.tsx. Do not count these as new.
